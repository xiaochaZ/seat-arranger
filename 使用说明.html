📚 班级排座位 — 使用说明

一款给班级排座位的免费小工具 · 纯前端 · 零依赖 · 完全离线

输入名单，设置规则（同桌/隔离/小组/固定座位/区域/禁坐，每条带权重），一键随机生成多套座位表，可视化微调，导出图片/Excel。

如何打开

  • 方式一：双击 index.html，浏览器打开即用。
  • 方式二（推荐）：用 Chrome 或 Edge 打开后，菜单 → 安装为应用 / 将此页面作为应用安装，桌面生成图标，双击像原生软件一样打开。
  • 数据保存在本机浏览器（localStorage），不上传任何地方，完全离线。

快速上手（四步）

①名单

  • 粘贴导入：把名单直接粘贴（每行一个姓名，自动去重，支持"1.张三"这类序号）。
  • 导入文件：支持 Excel/CSV/文本文件，自动识别"姓名"列（有表头时还会读学号/性别/身高/备注）。
  • 手动添加：点"＋ 添加学生"，可填姓名/学号/性别/身高/备注。
  • 可新建多个班级，顶部下拉切换，各班级数据独立。

👥 学生小组（给"选定的一批同学"建组）

  • 建组：在名单左侧勾选学生（表头复选框可全选）→ 点 ＋ 用勾选的 N 人建小组 → 输入组名（如"第一组""需要分开的 8 人"）。
  • 改成员：点小组胶囊进入编辑态，勾选/取消勾选即时保存；编辑完点 ✅ 完成编辑。胶囊可 ✏️ 重命名 或 ✕ 删除（删除时会提示有几条规则引用它，一并删除）。
  • 用途：小组可在「③ 规则」里用于「小组」规则：让组员两两保持距离（散开）或聚在一起坐成一块。改组成员后规则自动跟随，无需重建规则。

②布局

  • 设置排数/列数/门位置/过道位置，点"应用布局"。
  • 门位置：门在左侧或右侧，决定座位号从哪边数——门在左 → (1,1) 在最左边靠门；门在右 → (1,1) 在最右边靠门。
  • 过道位置：填过道在第几列后，多个用逗号分隔。
    • 2,4,6 → xx|xx|xx|xx（8 列分 4 组，每组 2 列）
    • 2,5,7 → xx|xxx|xx|xx（9 列，含 3 列组，可坐 3 人同桌）
    • 留空 → 无过道
  • 座位号：每个座位显示 (排,列) 坐标，如 (1,1)、(1,2)；同桌 = 同一排相邻两个（或三个）座位。
  • 区域：点"＋ 新建区域"命名（如"前排""靠窗"），选中区域后在网格中点击座位加入/移出该区域。
  • 不可用座位：在网格中右键座位标记"✕ 不可用"（如坏桌椅），排座时自动跳过。
  • 讲台默认在顶部，第 1 排靠讲台。

③规则

支持六类规则，每条可设权重（0~100，越高越优先满足）和硬约束（必须满足）：

规则作用示例
同桌2~3 人连排同桌张三 与 李四 同桌；或 张三+李四+王五 三人连排
隔离两人必须远离，可选：不同桌 / 曼哈顿距离至少 N 格 / 周围范围（对方前后 N 排、左右 N 座内都不能坐）王五 与 赵六 不能同桌；或相距至少 3 格；或"周围 1 排 1 座内都避开"（＝周围八个邻座都不行）
小组选定的一批同学作为一个整体：保持距离（组内两两远离）或聚在一起（组员两两同桌、座位拼成矩形、整组同一区域）「第一组」8 人之间相距至少 3 格；或「六人小组」聚到「前排」坐成一块
固定座位某同学锁定在某个座位周七 固定在 (1,1)（视力不好坐第一排）
区域某人必须坐进某区域近视的同学坐「前排」
禁坐某人禁止坐某处小明不能坐讲台旁
💡 3 人同桌需要布局中存在 ≥3 列的组（如过道设为 2,5,7），否则无法满足。
📏 「周围范围」怎么填（隔离与小组"保持距离"都适用）：禁坐区＝以对方为中心 前后 N 排 × 左右 M 座 的矩形，落在里面就算违规（同桌当然也不行）。
· 前后 1／左右 1 → 对方周围 3×3 的八个邻座都不能坐；
· 前后 0／左右 1 → 只看同一排的左右各 1 座（前后不限）；
· 前后 2／左右 0 → 只看同一列的前后各 2 排；
· 填 0 是"该方向只看正同一排/列"，不是"不限"；两个都填 0 等于没约束。
想要"只要不挨着就行"，用第一种模式 不能同桌 更直观。
🔒 固定座位勾选"硬约束"时：生成会把该同学直接预置到目标座位，拖拽也移不动他（座位显示金色虚线和 🔒），别人也占不走这个座位。若之后改了布局、该座位变成"不可用"，锁定会自动暂停并在生成时提示。
👥 小组的成员在「① 名单」页维护，规则里选「关系」：
· 保持距离（三种）：不能同桌 / 相距至少 N 格 / 周围范围（对方前后 N 排、左右 N 座内避开）—— 让组员散开（如上课爱聊天的几个人）；
· 聚在一起：组员两两同桌、座位尽量拼成一个矩形、整组落在同一个区域（还可指定"聚到某个区域"，如全坐「前排」）—— 让组员坐成一块（如学习小组、需要照看的一组）。
"聚在一起"里只有同桌和同一区域是硬要求；"拼成矩形"按尽可能处理——实在拼不成标准矩形时不会判失败，只在违规报告里用灰色"尽量"提示。 生成后小组成员会显示紫色 G1、G2 角标，方便核对。同一个学生/同一座位只能硬锁定一次，冲突时会提示。
⚖️ 权重会相互权衡：高权重规则优先满足，低权重"尽量满足"。硬约束无法同时满足时，生成的方案会标记 ⚠️ 并列出冲突。

④排座

  • 点 🎲 生成方案，一次生成多套（默认 10 套），按代价从低到高排列。
  • 点方案名切换查看；绿色边框=已满足的同桌关系，红色框+数字=违规座位，金色虚线+🔒=锁定的固定座位，紫色 G1/G2=小组成员。
  • 拖拽学生卡片可直接交换座位，松手后即时提示"新增/消除 X 条违规"；被锁定的学生拖不动，锁定座位也不允许别人占。
  • 右侧"违规报告"列出所有未满足规则，点条目可定位闪烁对应座位；灰色"尽量"条目表示"不影响方案有效、只是没能更理想"（如小组没能拼得足够紧凑）。
  • 满意后点 💾 保存当前方案（存档多套方便对比）。

导出与备份

功能说明
🖼 导出图片高清 PNG 座位表（含标题/日期/区域底色/违规标记），可直接打印或发班级群
📊 导出 Excel座位表 .xlsx（排/桌/列/姓名），Excel 直接打开
📦 备份配置整套数据（班级+布局+规则+方案）导出为 JSON；换电脑/清浏览器前先备份，之后在页面任意处导入恢复

常见问题

  • 换电脑数据没了？ 先用"📦 备份配置"导出 JSON 文件，到新电脑打开页面后点"📁 导入名单/备份"选择该 JSON 即可完整恢复（班级+布局+规则+方案）。
  • 人数比座位多？ 生成时会有明确提示，请到「布局」页加行列或取消不可用座位。
  • 规则冲突无解？ 降低权重或取消硬约束，或调整布局再生成。
  • 锁定的座位被标成"不可用"了？ 该锁定会自动暂停（规则不生效），重新选一个座位或恢复该座位即可。
  • 小组有人转走了？ 删除学生后小组会自动剔除该成员；点小组胶囊手动增减也可以。
  • 小组"聚成一块"没坐成矩形？ 布局/区域太窄或形状不规则时拼不出标准矩形，工具会尽量紧凑并在报告里提示；把该规则的"硬约束"取消可让它只作为"尽量满足"的软目标。
