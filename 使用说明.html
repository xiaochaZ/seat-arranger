📚 班级排座位 — 使用说明

一款给班级排座位的免费小工具 · 纯前端 · 零依赖 · 完全离线

输入名单，设置规则（同桌/隔离/区域/禁坐，每条带权重），一键随机生成多套座位表，可视化微调，导出图片/Excel。

如何打开

  • 方式一：双击 index.html，浏览器打开即用。
  • 方式二（推荐）：用 Chrome 或 Edge 打开后，菜单 → 安装为应用 / 将此页面作为应用安装，桌面生成图标，双击像原生软件一样打开。
  • 数据保存在本机浏览器（localStorage），不上传任何地方，完全离线。

快速上手（四步）

①名单

  • 粘贴导入：把名单直接粘贴（每行一个姓名，自动去重，支持"1.张三"这类序号）。
  • 导入文件：支持 Excel/CSV/文本文件，自动识别"姓名"列（有表头时还会读学号/性别/身高/备注）。
  • 手动添加：点"＋ 添加学生"，可填姓名/学号/性别/身高/备注。
  • 可新建多个班级，顶部下拉切换，各班级数据独立。

②布局

  • 设置排数/列数/门位置/过道位置，点"应用布局"。
  • 门位置：门在左侧或右侧，决定座位号从哪边数——门在左 → (1,1) 在最左边靠门；门在右 → (1,1) 在最右边靠门。
  • 过道位置：填过道在第几列后，多个用逗号分隔。
    • 2,4,6 → xx|xx|xx|xx（8 列分 4 组，每组 2 列）
    • 2,5,7 → xx|xxx|xx|xx（9 列，含 3 列组，可坐 3 人同桌）
    • 留空 → 无过道
  • 座位号：每个座位显示 (排,列) 坐标，如 (1,1)、(1,2)；同桌 = 同一排相邻两个（或三个）座位。
  • 区域：点"＋ 新建区域"命名（如"前排""靠窗"），选中区域后在网格中点击座位加入/移出该区域。
  • 不可用座位：在网格中右键座位标记"✕ 不可用"（如坏桌椅），排座时自动跳过。
  • 讲台默认在顶部，第 1 排靠讲台。

③规则

支持四类规则，每条可设权重（0~100，越高越优先满足）和硬约束（必须满足）：

规则作用示例
同桌2~3 人连排同桌张三 与 李四 同桌；或 张三+李四+王五 三人连排
隔离两人必须远离王五 与 赵六 不能同桌 / 至少隔 2 排
区域某人必须坐进某区域近视的同学坐「前排」
禁坐某人禁止坐某处小明不能坐讲台旁
💡 3 人同桌需要布局中存在 ≥3 列的组（如过道设为 2,5,7），否则无法满足。
⚖️ 权重会相互权衡：高权重规则优先满足，低权重"尽量满足"。硬约束无法同时满足时，生成的方案会标记 ⚠️ 并列出冲突。

④排座

  • 点 🎲 生成方案，一次生成多套（默认 10 套），按代价从低到高排列。
  • 点方案名切换查看；绿色边框=已满足的同桌关系，红色框+数字=违规座位。
  • 拖拽学生卡片可直接交换座位，松手后即时提示"新增/消除 X 条违规"。
  • 右侧"违规报告"列出所有未满足规则，点条目可定位闪烁对应座位。
  • 满意后点 💾 保存当前方案（存档多套方便对比）。

导出与备份

功能说明
🖼 导出图片高清 PNG 座位表（含标题/日期/区域底色/违规标记），可直接打印或发班级群
📊 导出 Excel座位表 .xlsx（排/桌/列/姓名），Excel 直接打开
📦 备份配置整套数据（班级+布局+规则+方案）导出为 JSON；换电脑/清浏览器前先备份，之后在页面任意处导入恢复

常见问题

  • 换电脑数据没了？ 先用"📦 备份配置"导出 JSON 文件，到新电脑打开页面后点"📁 导入名单/备份"选择该 JSON 即可完整恢复（班级+布局+规则+方案）。
  • 人数比座位多？ 生成时会有明确提示，请到「布局」页加行列或取消不可用座位。
  • 规则冲突无解？ 降低权重或取消硬约束，或调整布局再生成。
